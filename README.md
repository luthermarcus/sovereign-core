# Sovereign Core (v2.9.10-beta)

Ultra-lightweight, hardware-adaptive Bitcoin and DePIN settlement micro-OS layer operated via mobile Termux, Linux terminals, or containerized environments.

## What's New in v2.9.10-beta
- **Connection Health Auditor (`sovereign_crawler.py`):** Probes backend-registered ecosystems to detect available-but-unconnected network pathways and surfaces them on the TUI dashboard header.
- **Frontend-Backend Flag Synchronization:** Real-time visibility into unlinked routes and secure firewall rules.
- **Encrypted Sandbox Override & Visible Flags:** Safe developer bypass mode for beta testing with prominent header warning alerts.
