# Sovereign Core (v2.9.12-beta)

Ultra-lightweight, hardware-adaptive Bitcoin and DePIN settlement micro-OS layer operated via mobile Termux, Linux terminals, or containerized environments.

## What's New in v2.9.12-beta
- **UTXO Coin Control & Ledger:** Complete unspent transaction output tracking for advanced fee and privacy management.
- **Dynamic Fee Selection:** Multi-tier priority fee selection (Low, Normal, High) during transactions.
- **Interactive Guidance & Help Manual:** Built-in TUI help flags and tooltips designed to make every menu option self-explanatory.
- **Self-Custody Key Vault:** 100% client-side sovereign entropy seed generation.
