# Sovereign Core (`v2.6.3`)
An ultra-lightweight, hardware-adaptive Bitcoin and DePIN settlement micro-OS layer operated via mobile SSH (Termux) or Linux terminals.
* **Flash-Safe Storage:** Memory-mapped SQLite WAL with RAM temp-stores.
* **Security Shield:** Dynamic session cookie authentication (`rpc_auth.cookie`) and Address Poisoning dry-runs.
* **Interoperability:** HTLC atomic swaps and custom fee-rate transaction builders.
