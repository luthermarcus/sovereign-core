# Sovereign Core
**Lightweight, Hardware-Adaptive Bitcoin & DePIN Ecosystem**

![Version](https://img.shields.io/badge/version-v0.1.0--beta-blue)
![Network](https://img.shields.io/badge/network-Signet%20%2F%20Testnet-orange)

Sovereign Core is an ultra-lightweight cryptocurrency node built for vintage laptops and debloated Android phones via Termux. It bypasses the hardware bloat of modern blockchains by relying on Bitcoin SPV for consensus, while moving token swaps, app execution, and peer-to-peer routing into a localized SQLite engine.

Read `WHITEPAPER.md` for the full technical architecture.
